# 고객진단 상담 구성

상담 우선순위는 고객번호를 참조하지 않는다. 조회된 종합과세 대상·이력 제한, 0~30일 이내 만기, 추가 납입 여력 순으로 최대 두 건을 표시한다. 해당 사항이 없으면 자금 목적 확인을 먼저 제시한다. 과거 만기와 만기일 미확인 건은 임박 자금 합계에서 제외한다.

상품 현황은 당행 보유·미보유와 추가 활용·가입 제한을 함께 표시한다. 미보유는 타행 미가입이나 가입 자격 충족을 뜻하지 않는다. 소득 유형 자동 분류 근거와 상담 수정값을 구분해 표시한다.
