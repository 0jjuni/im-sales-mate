# 모닝 브리핑 검수 가이드 (담당자용)

매일 아침, 자동으로 쌓인 뉴스 **초안(draft)**을 훑고 이상 없는 것만 **발행(published)**한다.
발행한 것만 앱 화면에 뜬다. AI가 만든 초안이므로 **사실 확인은 사람이 한다.**

> 소요: 보통 5분 내. 하루 5~8건 정도만 검토하면 된다.

---

## 매일 아침 할 일

1. `briefing` 시트를 연다.
2. `status`가 **`draft`**인 행만 본다 (필터: status = draft 로 걸어두면 편함).
3. 각 행을 아래 **체크리스트**로 보고, 처리한다:
   - 이상 없음 → `status`를 `published`로 변경
   - 문구만 손보면 됨 → 고친 뒤 `published`
   - 부적절·중복·불확실 → **행 삭제** (또는 `status`를 `hold`로 두고 넘어가기)

## 행별 체크리스트

| 열 | 볼 것 |
|---|---|
| **summary** (사실) | 금리·한도·시행일 같은 **숫자·날짜가 맞나?** 원문/출처로 확인. 틀리면 고치거나 삭제. |
| **summary** | 아직 **확정 안 된 사안**을 확정처럼 썼나? → "논의 중 / 확정 전"으로 바로잡기. |
| **pbNote** (상담 포인트) | 창구에서 **단정적으로 안내하게** 유도하나? → 톤 완화. |
| **importance** | 오늘 꼭 알아야 하면 `high`, 아니면 `normal`. 하루 `high`는 2~3건이 적당. |
| **headline** | 한 줄로 명확한가? 낚시성·과장 있으면 다듬기. |
| **sourceUrl** | 출처 링크를 눌러 원문이 실제로 있는지 한 번 확인(할루시네이션 방지). |
| 전체 | **광고·개별 종목 추천·특정 상품 홍보**성이면 삭제. |

## 발행 후

- 며칠 지난 `published` 행은 그대로 둬도 되지만, 화면이 길어지면 오래된 것은 삭제하거나 `archived`로 바꾼다.
- 앱은 항상 **가장 최근 `date`의 published**를 보여준다.

## 판단이 애매할 때

- **숫자가 확실치 않으면 발행하지 않는다.** 창구 안내로 이어지므로, 애매한 건 빼는 쪽이 안전하다.
- 규제·세제 시행일 등은 **원문(보도자료)로 교차 확인**한다.
- 확정 전 정책은 반드시 "확정 전"임을 문장에 남긴다.

---

## 상태값 정리

| status | 의미 | 화면 노출 |
|---|---|---|
| `draft` | AI 초안, 미검수 | ✗ |
| `published` | 검수 완료, 발행 | ✓ |
| `hold` / `archived` / 기타 | 보류·보관 | ✗ |

`published`만 노출되므로, 확신이 없으면 `draft`로 두면 된다(그냥 안 건드리면 안 나간다).
