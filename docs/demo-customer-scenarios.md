# 세 고객 상담 시연

이름은 사용자가 지정한 시연용 가명이다. 진단·제안 규칙은 고객번호와 무관하며, 예시 조회 정보로 동일한 규칙을 실행한다.

## 김단디 · 841023391 · 기존 상품 관리
제조·도매업 대표. 종합과세 대상·이력 제한, 노란우산 월 20만원, 청약 월 10만원, 월적립 보험 추가 여력 월 70만원. 신한은행 결제계좌 이용.

1. 이름 버튼 선택 → 종합과세 이력과 제한 카드 확인.
2. 만기 예금 8,000만원의 사용 시점 확인.
3. 기존 보험 추가 납입과 노란우산 유지 상태 확인.
4. 맞춤 상품 제안의 연금 계산 화면으로 이동. 기존 연금 납입액은 고객에게 확인한 뒤 입력.
5. 진단 화면으로 돌아와 후속 상담 메모 기록.

## 이똑디 · 772501180 · 근로소득자 절세 상담
종합과세 비대상·이력 제한 없음. ISA·청약·개인카드 당행 미보유, 보험 추가 여력 2,000만원, 만기 예금 3,000만원.

1. 이름 버튼 선택 → 근로소득자 상품 현황 확인.
2. 타행 ISA 여부와 자금 사용 시점 질문. 고객 답변은 시연자가 말로 설명한다.
3. ISA 상담 시작 → 가입 조건과 계산 확인. 만기자금 전체를 곧바로 ISA에 넣는다고 설명하지 않는다.
4. 돌아와 연금 계산 또는 개인카드 안내 중 하나로 연결.
5. 재방문 일정을 메모로 기록.

## 박우디 · 904176624 · 개인사업자 신규 제안
소매점 운영. 현재 비대상이지만 직전 종합과세 이력 제한 있음. 노란우산·사업자카드 당행 미보유. 국민은행 결제계좌, 만기 예금 4,000만원.

1. 이름 버튼 선택 → ISA 제한과 제안 가능한 상품을 대조.
2. 노란우산 타기관 가입 여부 확인 → 미가입이라는 시연 답변 후 노란우산 상담·계산기로 이동.
3. 돌아와 기업카드 권유 → 사업 경비 결제 상품 확인.
4. 국민은행 결제계좌 이용 상태 확인 → 당행 전환 의향 질문. 조회되지 않는 매출 금액은 사용하지 않는다.
5. 다음 상담 준비 항목을 메모로 저장.

세 고객 모두 실제 가입·이체를 실행하는 시연이 아니라 조회 → 상담 → 계산·상품 안내 → 후속 관리 흐름이다. 고객 답변을 가정한 입력은 조회된 사실과 구분한다.
